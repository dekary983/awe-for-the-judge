A tiny Node program that writes one short text — rain falling on an unwatched lake for ten thousand years — meant to slow its reader down. The text is 278 characters; the program writes it, unchanged, to the output directory as entry.txt.

## Run it

```sh
node main.ts
```

It writes entry.txt into $MAKEFUN_OUTPUT_DIR, or /output when that variable is unset.
